Imports title.ratings.tsv.gz and title.basics.tsv.gz into IndexedDB once. Roughly a gigabyte is read and a few hundred megabytes are stored, so it takes a few minutes. Keep this tab open while it runs. IMDb publishes these dumps for personal, non-commercial use.

Titles with fewer votes are skipped, which keeps the store small. 100 is a good balance; raise it to 1000 for a much smaller database that still covers the storefront.

OMDb

Stored only in this browser's extension storage. Free keys allow roughly 1000 lookups a day; the extension keeps its own count and stops before the API cuts it off.
